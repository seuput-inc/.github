## 만드는 것 · What we build

| | 한국어 | English |
|---|---|---|
| **[SeuOffice](https://github.com/seuput-inc/seuoffice)** | 웹과 PC에서 PDF, 워드, 엑셀, 파워포인트, 한글 문서를 보고 고치고, AI로 편집하는 오피스입니다. | An office suite for the web and desktop: open and edit PDF, Word, Excel, PowerPoint and HWP documents, with AI editing. |
| **[OMPdesk](https://github.com/SeuPut0705/ompdesk)** | omp 코딩 에이전트용 데스크톱 앱입니다. 여러 세션을 나란히 돌리고, Autopilot으로 맡기고, 휴대폰으로 이어 봅니다. | The desktop app for the omp coding agent: parallel sessions, Autopilot, and your phone. |
